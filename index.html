Spoken Margins test feeds

Fake “paid” podcast feeds for testing link privacy. Every token is made up.

Tap Copy next to a feed (or long-press its link and choose Copy Link), then in the app use Library → + → Link or Podcast → Paste. Copy a feed link, not this page’s address: the page itself imports as an article.

After sharing a Margin from a private feed, the packet should not contain the subscriber tokens, which begin FAKEsubA or FAKEsubB. Each feed holds one short episode.
